# Zara UI/UX Redesign: Live Comparison Prototype

Course: Designing User Interfaces (HHN x VGU) · Team: Khương, Dung, Thuần, Linh, Hiếu
Student concept, not linked to Zara or Inditex.

## The idea
One page with **two phones**:

| Left: BEFORE | Middle | Right: AFTER |
|---|---|---|
| Real screenshot of today's app (from our audit), with red numbered circles on each problem | Problem → fix cards for the current screen | Clickable redesign |

When you tap the **new** phone, the **old** phone jumps to the same step at once.

## Flows
- Flow 1: Categories → Coats → product → size → bag → review → bank → result
- Flow 2: Search → suggestion → product → bag (change size) → checkout
- Extra: Cookies (first launch), Account → Log in / Register, Returns (4 steps), Help
